# Headless E-Commerce Platform (Next.js + WordPress)

This repository contains the code for a Headless E-Commerce platform.
- **Frontend:** Next.js (App Router, Server Components)
- **Backend:** WordPress + WooCommerce + Carbon Fields

This guide provides instructions for local development and deploying the project via Git to a standard web server (without Docker).

---

## 🚀 Part 1: Local Setup (Development)

### Prerequisites
Before you begin, ensure you have the following installed:
- **Node.js** (v18 or higher) & npm.
- **Local Web Server** (e.g., [LocalWP](https://localwp.com/), XAMPP, or MAMP).
- **Git** for version control.
